# 외부 코드와 이미지

- JSZip 3.10.1은 `dist/jszip.min.js`에 포함되어 있습니다. MIT 라이선스 사용을 선택하며 원 라이선스 전문은 `dist/jszip-LICENSE.txt`에 보존했습니다. 외부 CDN이나 npm 설치 없이 엑셀 ZIP 내보내기에 사용됩니다. 버전과 파일 해시는 `source-provenance.json`에 기록되어 있습니다.
- 제품·유리·랩핑·핸들 참고 이미지 및 대산 로고는 원 프로젝트에서 사용하던 5개 PNG를 그대로 포함했습니다. 회사·제품 자료의 권리가 이 저장소 업로드로 제3자에게 이전되는 것은 아닙니다. 전체 앱에 새로운 오픈소스 라이선스를 임의로 부여하지 않았습니다.
- `dist/app.js`와 `dist/report.js`는 원본 구현 코드이며 제품 목록·색상 코드·추천 사양 데이터가 이 파일들에 포함됩니다. 별도 제품 DB나 숨겨진 소스 패키지는 없습니다.
